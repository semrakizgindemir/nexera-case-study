## What is a skill profile?
A skill profile is a structured summary of what a person can do. It
combines technical skills, tools, and soft skills. A clear profile helps
match a person to the right opportunities.

## How to grow a skill
1. Pick one concrete skill with a clear outcome.
2. Practice it on a small real project.
3. Get feedback and review your work.
4. Repeat with slightly harder projects.

## Technical vs soft skills
Technical skills are measurable abilities such as writing code or
analyzing data. Soft skills are how you work with others, such as
communication, ownership, and time management. Strong candidates show
both.

## Common beginner mistakes
- Trying to learn too many things at once.
- Skipping the fundamentals.
- Never finishing a project end to end.
- Not asking for feedback early.

# Learning Paths (Sample Content)

> Fictional sample data for the case study. Not real product data.

## Backend Developer Path
A typical backend path starts with one programming language and its
fundamentals, then moves to web frameworks, databases, and APIs.
Suggested order:
1. Language fundamentals (for example Python or Node.js)
2. Relational databases and SQL
3. Building REST APIs
4. Authentication and security basics
5. Caching, queues, and background jobs
6. Containers and basic deployment

Estimated duration: 4 to 6 months at a steady pace.

## Frontend Developer Path
1. HTML, CSS, and JavaScript fundamentals
2. A component framework (for example React)
3. State management and data fetching
4. Accessibility and responsive design
5. Testing and performance basics

Estimated duration: 3 to 5 months at a steady pace.

## Data and Machine Learning Path
1. Python and data libraries (pandas, numpy)
2. Data cleaning and exploratory analysis
3. Classical machine learning models
4. Model evaluation and validation
5. A first end to end project

Estimated duration: 5 to 7 months at a steady pace.
